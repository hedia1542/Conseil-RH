Rédiger un compte rendu de visite client

Une trame courte pour garder une trace utile de chaque rendez-vous dans le CRM.

Proposition de contenu à valider par l’équipe pédagogique ESMC. Adaptez toujours les conseils à votre entreprise et demandez l’avis de votre tuteur ou de vos formateurs.

1Objectif

Garder une trace claire de chaque rendez-vous pour assurer le suivi et partager l’information avec l’équipe.

2Étapes

  1. Rédigez le compte rendu le jour même, quand vos souvenirs sont précis.
  2. Notez les faits : besoins exprimés, interlocuteurs, budget, délais.
  3. Distinguez les faits de vos impressions.
  4. Indiquez les engagements pris de chaque côté.
  5. Fixez la prochaine action avec une date, puis enregistrez le tout dans le CRM.

3Exemple concret

Prochaine action (exemple fictif)
« Envoyer le devis pour 3 postes avant vendredi 12. Rappeler M. Leroy le mardi 16 pour recueillir son avis. »

Exemple d’illustration, à adapter à votre situation.
